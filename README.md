# Server Plugin Builds

Gotowe pliki JAR do pobrania:

- `SoulSpawner-17.jar` — asynchroniczny i atomowy zapis klatek.
- `IslandWorld-22.1.jar` — bezpieczne, porcjowane wklejanie schematow wysp.
- `UJobs-1.3.0.jar` — zbiorcze wyplaty i odciazenie obslugi niszczenia blokow.
  Przy pierwszym starcie Paper pobierze oficjalne biblioteki Caffeine i SQLite JDBC.

Po podmianie pluginow wykonaj pelny restart serwera. Nie uzywaj `/reload`.
